# EP1–EP5 일러스트 제작 기준

## 그림 기준

- 세로 4:5 컷, 현대 한국 컬러 웹툰을 위한 2D 일러스트
- 또렷한 선화와 부드러운 채색, 따뜻한 실내광과 장면에 맞는 차가운 그림자
- 인물의 눈·입·손·자세에서 대사의 감정이 읽히도록 연출
- 인물 크기, 시점, 거리와 배경 소품을 컷마다 달리해 스크롤 리듬을 만든다
- 티몽은 둥근 인상, 짧고 약간 헝클어진 검은 머리와 관자놀이의 새치, 평균 체형을 유지한다
- 현재의 집 장면은 흰 티셔츠와 어두운 바지, 회상 장면은 당시 나이와 복장에 맞게 표현한다
- EP1의 새 지도는 깨끗한 종이, EP5의 오래된 지도는 누렇게 바랜 종이와 닳은 접힘 자국·연필 경로로 구분한다

## 글자와 모바일 읽기

- 일러스트 파일에는 대사, 글자, 컷 번호를 넣지 않는다
- 대사와 내레이션은 `data/dialogues.js`의 별도 텍스트 레이어에서 표시한다
- 둥근 흰 말풍선 캡션은 읽기 화면 CSS로 그려, 모바일 폭에서도 글자가 크게 유지되도록 한다
- 대사가 없는 정적 컷은 빈 캡션을 억지로 표시하지 않는다

## 연속성 검수

- 이미지 순서와 대사 배열은 회차별 컷 번호로 1:1 대응한다
- EP1–EP5는 각각 20·20·20·20·14컷이다
- EP2의 예산 장면은 특정 금액을 이미지에 생성하지 않는다. 실제 가정·근거는 원고에서 검토 가능한 텍스트로 다룬다
- EP3의 AI는 초안과 정리를 돕는 보조 도구이며, 수익을 보장하는 장치로 묘사하지 않는다
- EP4는 가족의 의견과 일정이 반영되는 대화로 이어진다
- EP5의 마지막 반사 장면은 현재 티몽과 스무 살 무렵의 티몽을 얼굴·체형·머리로 구분한다

## 배포 형식

- 컷 원고는 WebP로 저장하고 `data/episodes.js`에 순서대로 등록한다
- 원본 비율을 유지하며, 가로 640px 이상을 품질 하한으로 확인한다
- 공개 전 Node 테스트와 이미지 헤더·경로 검사를 실행한다
