## 4. 화면(UI) 컷 처리 방법
컷 3·5·6·8·10에는 정확한 숫자와 한글이 들어간다. 이미지 생성 모델은 한글과 숫자를 자주 틀리게 그리므로 다음 순서로 만든다.

1. 그림 생성: 손과 **빈 화면**의 휴대전화(또는 화면 테두리)만 그린다.
2. 화면 UI: 디자인 도구에서 은행 앱 화면을 따로 만든다 — 파란 머리띠 `#365E9A`, 흰 바탕, 검은 숫자, 은행 건물 아이콘(2화 19·20컷과 같은 모양).
3. 합성: 화면 위에 UI를 원근에 맞춰 얹고, 화면 빛을 얼굴·손에 덧칠한다.

## 5. 컷별 검수 항목
각 컷마다 아래를 확인하고 결과를 6절 표에 적는다.

- [ ] 머리 모양·눈썹·체형이 참조 시트와 같다 (`character-bible.md` 1절)
- [ ] 흰 반팔 티셔츠 + 어두운 바지 (3화 전체)
- [ ] 얼굴, 손, 휴대전화, 노트가 컷 테두리에 잘리지 않는다 (컷 2의 엄지, 컷 5의 양손은 일부러 자르는 것이므로 예외)
- [ ] 말풍선이 얼굴과 중요한 소품을 가리지 않는다
- [ ] 글자 높이 41px 이상(1080px 기준), 상자 2개 이하
- [ ] 번호 상자가 테두리 안쪽에 온전히 있다
- [ ] 바깥 여백에 다른 컷 그림 조각이 없다
- [ ] 숫자가 대본과 같다(3,400~5,200만 원 / 1,284,560원), 대출 금액은 보이지 않는다
- [ ] 달력이 보이면 「2026. 8」, 액자는 1화 10컷의 바닷가 네 식구
- [ ] 아내의 모습이 보이지 않는다(컷 13·14)
- [ ] 가로 ≥ 640px, 세로÷가로 ≤ 2.0, JPG
- [ ] 컷 14 아래 예고 띠 제목이 `data/episodes.js` 4화와 같다

## 8. 합성 도구 사용법
그림과 글자를 분리해 만든다. AI 이미지 생성은 스크립트에 들어 있지 않다.

1. 그림(글자 없는 컷 그림)을 `production/003/art/NN.png`로 넣는다. 크기는 3절 표의 크기(1080px 폭)가 가장 좋고, 다르면 가운데 기준으로 채워 자른다.
2. 화면·노트가 나오는 컷(1·2·5·6·8·11·12)은 그림 속 화면 네 모서리 좌표를 `scripts/production/compose_003.py`의 `OVERLAYS`에 `quad`로 적는다.
3. `python3 scripts/production/compose_003.py`를 실행한다. `episodes/003/NN.jpg`와 `production/003/qa-report.md`가 만들어진다.
4. 글자 배치만 보려면 `--preview <폴더>`로 실행한다.
5. 얼굴·손·소품 잘림과 인물 일관성은 5절 체크리스트로 사람이 확인한 뒤 6절에 적는다.

- 글꼴: Noto Sans KR(대사), Jua(노트 손글씨). 둘 다 SIL Open Font License이며, 없으면 스크립트가 `production/fonts/`로 내려받는다(저장소에는 넣지 않음).
- 3화는 14컷 모두 검수를 통과하기 전까지 `MANUSCRIPTS`에 등록하지 않는다.
